#  Mejora del tiempo de empaque y entrega en panadería

**Proyecto Capstone · Six Sigma Green Belt (Kennesaw State University) · Metodología DMAIC**
Autor: **Abraham García** · Jun–Ago 2025

> **Resultado en una línea:** con un rediseño del área de empaque, el tiempo promedio por lote bajó **33.6 %** (11.77 → 7.82 min, p < 0.001) y los pedidos listos a las 07:30 subieron de **73.3 % a 90 %** en el piloto.

##  Problema
Solo 22 de 30 pedidos (73.3 %) estaban listos a las 07:30, la hora de salida del reparto. Las entregas tardías y los errores de surtido generaban descuentos, devoluciones y cancelaciones, con una pérdida estimada superior a $20,000 MXN al mes. Meta: **95 %**.

##  Qué hice (DMAIC)
| Fase | Actividades |
|---|---|
| **Define** | Project Charter, Team Charter, SIPOC, objetivo SMART |
| **Measure** | Plan de recolección de datos, VOC/CTQ, línea base (30 pedidos) |
| **Analyze** | Mapa AS-IS, Ishikawa, pruebas de hipótesis, DPMO y nivel Sigma |
| **Improve** | Rediseño de layout, separación de surtido y empaque, etiquetas por color, checklist de materiales (matriz de selección ponderada) |
| **Control** | Plan de control con carta de individuales, 5S y gestión visual |

## 📊 Resultados del piloto
| Indicador | Línea base | Piloto | Cambio | Evidencia |
|---|---|---|---|---|
| Tiempo prom. de empaque por lote | 11.77 min | 7.82 min | −33.6 % | Significativo (Welch, p < 0.001) |
| Pedidos a tiempo | 73.3 % | 90.0 % | +16.7 pp | Sugestiva, no concluyente (Fisher p = 0.090) |
| Errores de surtido | 3.3 % | 0 % | −3.3 pp | No significativa (n pequeña) |
| Nivel Sigma | 2.12σ | 2.78σ | +0.66σ | Meta: 3.14σ |

La meta de 95 % **aún no se alcanza**; el plan de control y la fase de validación buscan cerrar la brecha.
